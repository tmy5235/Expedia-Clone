# Documentation Guidance

## Selected instruction

> Keep the documentation close to the Hello Agent structure. Maintain setup and run instructions in `README.md`, project-specific rules in `AGENTS.md`, a brief design note, selected prompts, and a current handoff. Include only the additional requirements this project needs.

## Result

The root README and AGENTS files follow the Hello Agent layout. The design note explains component responsibilities, and the handoff records the current implementation, checks, limitations, and next task without repeating the full assignment.
